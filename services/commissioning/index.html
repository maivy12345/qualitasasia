The need

Systems must work together, not only pass in isolation.

Commissioning establishes the sequence, interfaces and evidence needed to verify component, system and integrated performance against the owner's requirements.

Cx planningFAT / SATFunctional testsISTIssue closure
Scope

Commissioning from design review to aftercare.

Programmes are built around system dependencies, safe test conditions and operational outcomes.

01

Strategy and planning

Define systems, levels, responsibilities, prerequisites, programme logic and evidence.

02

Commissionability review

Review access, isolation, controls, instrumentation and test provisions before installation.

03

Test documentation

Develop or review procedures, scripts, method statements and acceptance criteria.

04

Witnessing and coordination

Coordinate readiness, witness execution and record objective test evidence.

05

Integrated systems testing

Verify response to realistic operating and failure scenarios across connected systems.

Verification sequence

Build confidence level by level.

Each level should satisfy prerequisites before the next introduces wider integration and operational consequence.

Define
